# Sentinel como extensión opcional

Sentinel amplía el Inspector con monitoreo continuo, API Go, PostgreSQL, Server-Sent Events, autenticación, observabilidad y notificaciones. Ese trabajo demuestra una evolución posible del producto, pero supera el alcance formal del instrumento frontend.

## Separación de alcance

- **Entrega evaluada:** rama [`main`](https://github.com/VillaAlexTor/Stellar-account-inspector/tree/main), con Inspector y Risk Score de frontend puro.
- **Extensión de portafolio:** rama [`Retro`](https://github.com/VillaAlexTor/Stellar-account-inspector/tree/Retro), con la implementación completa de Sentinel y su documentación operativa.

La extensión no es una dependencia, requisito ni parte de la demostración del curso. Se conserva para trazabilidad técnica y presentación de portafolio.
